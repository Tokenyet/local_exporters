Privacy

Local processing, clear boundaries.

Local Exporters is designed to keep generated media and native processing on the user's Windows computer.

What is stored

Each extension stores user preferences in chrome.storage.sync, such as output folder text, export mode, file format preferences, chat settings for Twitch, and subtitle settings.

What leaves the browser

When the user starts an export, the extension sends the authorized page URL and selected export options to its local native messaging host. The native host uses local helper tools to retrieve and convert the requested content.

What is not collected

The project does not operate analytics, advertising, cloud transcription, or a developer upload service for generated media. Exported files and downloaded helper tools remain on the user's selected local storage.

User responsibility

Use the extensions only for content you own or are authorized to export. The third-party sites and tools used during an export may have their own terms and privacy policies.

Questions

See the support page or open an issue in the source repository. Do not include cookies, access tokens, or private media URLs.
