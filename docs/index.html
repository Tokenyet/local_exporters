Why I built this

The useful part of a livestream is often the part you did not have time to watch.

I kept reaching the same dead end: there was a stream I wanted to catch up on, but no transcript existed. Without text, an AI summarizer had nothing reliable to work with. Local Exporters started as a practical way around that problem.

YouTube

“There is a livestream I want to understand, but it has no subtitles.”

No subtitles means no transcript—and no useful summary.

YouTube Local Exporter first uses available captions. When they are missing, it can run Whisper locally and produce SRT or VTT files that can be reviewed or passed to a summarization tool.

  • Use YouTube captions when available
  • Generate missing subtitles with local Whisper
  • Export video or audio when more context is needed
Twitch

“I follow chat-focused streamers, but sometimes I cannot be there live.”

I wanted to know what people had been talking about.

Twitch Local Exporter turns a VOD into subtitles and optional chat logs, giving long conversational streams enough structure to build an outline and decide which parts are worth watching.

  • Create subtitles from the VOD audio
  • Export chat as JSON, HTML, or plain text
  • Keep conversation context beside the transcript
↗

Local Exporters prepares the source material; it does not choose an AI provider for you. The transcript, chat, audio, and video stay as ordinary files on your computer, so you decide what happens next.

Technical concept

The browser asks. Windows does the work.

The extension is intentionally thin. Downloading, remuxing, transcription, chat export, progress, and cancellation run through a local native messaging host.

GPU

Whisper chooses the useful backend

On NVIDIA systems, the host prefers the CUDA/cuBLAS Whisper binary. If CUDA startup fails—or no NVIDIA GPU is present—it falls back to CPU transcription.

CLI

Existing tools are reused

Clean install probes working CLI commands already available on PATH. Bundled downloads are installed only when a required tool is missing or unusable.

PC

Processing stays local

There is no developer media-upload service or cloud transcription backend. Generated files are written to the output folder you select.
