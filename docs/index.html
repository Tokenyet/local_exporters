One shared toolchain

Both extensions reuse common downloads such as yt-dlp, Deno, FFmpeg, Whisper.cpp, and model files. The default location is:

%LOCALAPPDATA%\com.dowen.local_exporter\toolchain

Product-specific tools remain isolated under products\twitch and products\youtube. Shared, isolated, and custom locations are supported by the installers.

Designed for local control

Browser UI

Start an export from the active Twitch or YouTube page only when you choose to use the extension.

Windows native host

Run downloads, conversion, subtitles, and chat export locally with visible progress and cancellation.

Independent products

Each extension keeps its own permissions, native host, release package, and product-specific behavior.
