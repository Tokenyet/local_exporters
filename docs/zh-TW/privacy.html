隱私權

本機處理，清楚的資料界線。

Local Exporters 的設計目標，是讓產生的媒體與 native 處理流程留在使用者的 Windows 電腦上。

儲存哪些資料

每個擴充功能會在 chrome.storage.sync 儲存使用者偏好，例如輸出資料夾文字、匯出模式、檔案格式、Twitch 聊天室設定與字幕設定。

哪些資料會離開瀏覽器

使用者開始匯出時，擴充功能會把已獲授權的頁面網址與所選設定傳給本機 native messaging host。Native host 再使用本機輔助工具取得並轉換指定內容。

不會收集哪些資料

本專案不提供分析追蹤、廣告、雲端轉錄或開發者營運的媒體上傳服務。匯出的檔案與下載的輔助工具會留在使用者選擇的本機儲存空間。

使用者責任

請只對自己擁有或已獲授權的內容使用這些擴充功能。匯出過程中使用的第三方網站與工具，可能有各自的使用條款與隱私政策。

問題與聯絡

請參考支援頁面，或到原始碼儲存庫提出 Issue。請勿附上 cookies、access token 或私人媒體網址。
