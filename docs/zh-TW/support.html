讓本機安裝流程保持清楚。

大部分安裝問題來自舊的 native host 登錄、過期的 extension ID，或工具被安裝在不同的 toolchain 位置。

完整重新安裝

Manifest 已包含固定的公開簽章金鑰。如有需要，可執行 scripts\show-extension-ids.ps1 查看固定 ID，再建立 unpacked extension、移除舊的 native host 登錄，並在 Windows 預設 HTTPS 瀏覽器中重新登錄兩個 native host：

.\scripts\package-all.ps1
.\scripts\clean-install.ps1

需要在所有支援的瀏覽器中登錄 native host 時，請加上 -Browser all。

Windows 上的 Vivaldi

Vivaldi 在 Windows 使用 Chromium 的 Chrome native messaging 登錄位置。因此 native host 必須登錄在 HKCU\Software\Google\Chrome\NativeMessagingHosts，不能只放在 HKCU\Software\Vivaldi\NativeMessagingHosts。Clean install 後若彈出視窗仍顯示無法連接 host，請重新啟動 Vivaldi，並從 vivaldi://extensions 重新載入兩個 unpacked extension。

共用工具

.\scripts\clean-install.ps1 預設會執行兩個共用工具鏈更新程式，因此完整重裝會包含 native host 與工具。更新程式會先測試 PATH 中可用的 CLI，避免重複下載；需要強制安裝內附版本時使用 -ForceUpdate。只想修復 native host 登錄而不檢查工具時，使用 -SkipUpdateTools。第二個更新程式會重用 %LOCALAPPDATA%\com.dowen.local_exporter\toolchain 中的共用檔案。

Native host 診斷

可以從擴充功能彈出視窗查看 native host 狀態，或執行對應產品的 native-host tests。狀態資訊包含實際使用的 toolchain 模式與根目錄。若從新資料夾重新載入擴充功能，請用新的 extension ID 重新安裝 native host。

回報問題

請在 GitHub Issue 提供產品名稱、Windows 版本、瀏覽器、擴充功能版本，以及最小範圍的相關錯誤訊息。請勿附上 cookies、access token 或私人媒體網址。
