為什麼寫這個

直播真正有用的部分，往往正是你沒時間看的那一段。

我一直遇到同一個問題：有一場想補看的直播，卻沒有逐字稿。沒有文字，AI 摘要工具也缺少可靠的來源。Local Exporters 就是為了解決這個實際問題而開始的。

YouTube

「有一場直播想了解，但它沒有字幕。」

沒有字幕，就沒有逐字稿，也很難得到有用的摘要。

YouTube Local Exporter 會優先使用現有字幕；字幕不存在時，可以在本機執行 Whisper，產生可閱讀或交給摘要工具的 SRT／VTT 檔案。

  • 有 YouTube 字幕時優先使用
  • 缺少字幕時以本機 Whisper 產生
  • 需要更多上下文時可匯出影片或音訊
Twitch

「常看的實況主以聊天為主，但有時候沒空跟臺。」

我想知道之前到底討論了什麼。

Twitch Local Exporter 能把 VOD 轉成字幕並選擇性匯出聊天室，讓長時間的聊天型直播有足夠結構可整理大綱，也能先判斷哪些片段值得回去看。

  • 從 VOD 音訊建立字幕
  • 聊天室可匯出為 JSON、HTML 或純文字
  • 讓逐字稿旁保留對話脈絡
↗

Local Exporters 負責準備來源資料，不替你選擇 AI 服務。逐字稿、聊天室、音訊與影片都是電腦上的一般檔案，接下來要怎麼使用由你決定。

兩個匯出工具

直接在正在觀看的頁面上選擇需要的內容。

兩個產品是各自獨立的 Chromium 擴充功能，有不同權限、native host 與發行套件，但共用相同、專注於工作的匯出流程。

01Twitch Local Exporter

把 VOD 媒體、字幕與聊天室放在一起。

在彈出視窗選擇影片、音訊、字幕或聊天室。本機 native host 處理工作時，仍可看到進度並隨時取消。

MP4音訊SRT / VTT聊天室 JSON / HTML / TXT

02YouTube Local Exporter

GPU

Whisper 自動選擇合適的後端

NVIDIA 系統會優先使用 CUDA／cuBLAS Whisper。CUDA 啟動失敗或沒有 NVIDIA GPU 時，則自動退回 CPU 轉錄。

CLI

重用電腦上已有的工具

Clean install 會先測試 PATH 中現有的 CLI 指令。只有缺少必要工具或指令無法使用時，才下載內附版本。
