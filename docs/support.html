Support

Keep the local path understandable.

Most installation problems are caused by an old native host registration, a stale extension ID, or tools installed in a different toolchain location.

Clean reinstall

On Windows, the manifests include stable public signing keys. Run scripts\show-extension-ids.ps1 to inspect the fixed IDs if needed, then build the unpacked extensions, remove old native registrations, and register both native hosts without passing IDs manually:

.\scripts\package-all.ps1
.\scripts\clean-install.ps1

Use -Browser all when every supported browser should receive the native host registration.

macOS clean reinstall

Use the shell entry points on macOS. They derive the stable IDs from each manifest and register native messaging manifests under the selected Chromium browser's Application Support directory:

./scripts/show-extension-ids.sh
./scripts/package-all.sh
./scripts/clean-install.sh --browser chrome

Vivaldi on Windows

Vivaldi uses Chromium's Chrome native-messaging registry root on Windows. The native host must therefore be registered under HKCU\Software\Google\Chrome\NativeMessagingHosts, not only under HKCU\Software\Vivaldi\NativeMessagingHosts. If the popup says the host is not connected after a clean install, restart Vivaldi and reload both unpacked extensions from vivaldi://extensions.

Shared tools

.\scripts\clean-install.ps1 on Windows and ./scripts/clean-install.sh on macOS run both shared-toolchain updaters by default. The updaters first probe working CLI commands on PATH and avoid downloading duplicates; use the platform's force-update option when you explicitly want bundled copies. The macOS shared toolchain is under ~/Library/Application Support/com.dowen.local_exporter/toolchain.

Native host diagnostics

Check the extension's native host status from its popup or run the product's native-host tests. The status includes the resolved toolchain mode and root. If an extension was reloaded from a new folder, reinstall the native host with the new extension ID.

Report a problem

Open an issue with the product name, OS version, browser, extension version, and the smallest relevant error message. Do not attach cookies, access tokens, or private media URLs.
